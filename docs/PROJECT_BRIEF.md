## 1. これは何か（30秒版）

**『壁打ち――観測社会の密室』**：不登校・教育・見守り社会をテーマにした自作SFミステリー小説（全24話・約10万字）と、それを原作にした**ブラウザで動く没入型アドベンチャーゲーム**のプロジェクト。

あらすじ：すべての子どもに「ちょうどいい難易度」の人生が配信され、不登校が統計上消滅した2049年。システムが「良好」と観測していた16歳の少年が死んだ。調査するのは、経歴欄が空白の男――システム導入前に社会からこぼれ落ちた、最後の未測定世代。

テーマの核：「観測・採点されると、居場所は壊れる」「回復が先、負荷は後」。作者自身の不登校経験と社会学・教育学の理論（ヴィゴツキー、パットナム、苅谷剛彦ほか）が下敷き。説教にならないよう、思想はすべて事件とゲームメカニクスの形で提示している。

### 3D版の内容
- 一人称視点で夜の旧市街を探索（Three.js製、Unity不使用、アセット完全プロシージャル）
- 現場検証→証拠収集→会話（タイプライター演出・選択肢）→異空間「壁打ち」
- 最後にゲームがプレイヤー自身の行動記録（プレイ時間・決断速度など）を開示するメタ演出
- PC（WASD＋マウス）とスマホ（仮想スティック）両対応。依存ゼロの単一HTMLファイル

### 技術的な特徴（配布の観点で重要）
- **1ファイル500KBで、サーバー処理不要。どこにでも置けて、リンクを踏めば即遊べる**
- 外部送信なし（テレメトリ演出は端末内のみ）。プライバシー面がクリーン
- 続編・別小説を追加できるプラットフォーム設計（エンジンとシナリオが分離）

## 5. 現時点の推奨プラン（三段階）

1. **今週：Web公開＋導線づくり**
   GitHub Pagesを有効化して固定URLを取得 → itch.io にページ作成（スクショ4枚＋紹介文） → tales に小説を連載開始し、各話末尾にゲームURLを置く。
2. **今月：日本のフリゲ窓口＋告知**
   PLiCy・ふりーむに登録。Xでプレイ動画GIF付きの告知（週1〜2回、開発進捗も出す）。反応データ（どこから人が来たか）を見る。
3. **完全版のあとで：ストア展開**
   第二部・第三部＋対決パートを実装した完全版ができた段階で、iOS（Capacitorでラップ、買い切りor無料）を検討。Steamはその次。

理由：この作品の強みは「リンク1つで30秒後に遊べる」こと。まず無料Webで母数と感想を集め、その実績と完成度を持ってストアに行く方が、審査リスクも宣伝効率も良い。

## 6. Claudeに相談したい論点（このまま質問に使ってください）

1. itch.io のページに載せる**英語・日本語の紹介文**を、この作品の魅力（観測社会ミステリー×メタ演出）が伝わる形で書いてほしい
2. X告知用の**最初の1ポスト**（140字＋添付画像の構成案）を考えてほしい
3. 体験版の**タイトル画面に載せるキャッチコピー**の候補を10個
4. ペンネーム運用で身元を出さずに活動する場合の注意点（就活との両立）
5. iOSアプリ化するとき、審査ガイドライン4.2（最小限の機能）を回避するために足すべき「アプリらしい機能」の優先順位
6. 小説（tales）とゲームの相互導線の具体的な文言
7. 遊んだ人が感想を送りたくなる仕掛け（外部送信なしの方針と両立する形で）
